# 紙上的法律，山裡的現實：原民獵槍新制上路後的平行時空

原住民自製獵槍新制專題網頁。版面沿用〈同一個起點，男性和女性的路一路分岔〉：紙張格線背景、黑框卡片、等寬字小標。

## 章節

1. **開場**：p5.js 動態標題（`js/title.js`）
2. **跟**：導言與引言
3. **四十年**：1983–2025 制度時間軸
4. **舊槍**：2017 警政署委託研究的 32 件意外點陣與問卷數字
5. **兩把槍**：甲式／乙式立體素描互動（`js/gun-sketch.js`）
6. **平行時空**：訓練、甲式、乙式、信任四張卡
7. **限制**與來源

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 網頁本體，文字都在這裡改 |
| `css/style.css` | 版面樣式；甲式色 `--a`、乙式色 `--b` |
| `js/title.js` | 標題動畫，文字顏色在開頭 `CONFIG` |
| `js/gun-sketch.js` | 槍枝素描：部位多邊形座標（依照片描）、明暗、排線、視差、分離 |
| `js/page.js` | 閱讀進度、意外點陣、部位說明文字 `INFO` |
| `js/lib/p5.min.js` | p5.js 1.11.3（LGPL-2.1） |
| `assets/` | 兩張實物影像截圖 |
| `figures/` | 靜態版對照圖 |
| `notes/sources.md` | 來源、查核與待補 |

## 預覽

`index.html` 用 p5 載入照片，直接雙擊開檔時「原照」可能載不出來。請在資料夾裡執行 `python3 -m http.server`，再開 <http://localhost:8000>。

- `assets/` 的照片屬原住民族電視台、花蓮縣警察局／中央社，**取得授權前不要推到公開的 GitHub Pages**。
