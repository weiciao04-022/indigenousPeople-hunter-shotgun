# 紙上的法律，山裡的現實：原民獵槍新制上路後的平行時空

原住民自製獵槍新制專題的網頁原型，包含：

- **p5.js 動態標題**（`js/title.js`）：左邊「紙上的法律」用明體加墨色漸層，底下有公文格線；右邊「山裡的現實」的「山」換成山峰圖形，「現」填入雲豹雲紋，「實」垂下一條環紋尾巴。標題下方有一條線，從公文直線漸漸變成山稜線。點一下標題可重播動畫。
- **甲式／乙式外觀部位互動比較**（`js/compare.js`）：點部位看兩件樣本的說明；「分離」可把外觀部位拉開，「原照」可把線稿疊回照片核對。
- **靜態版對照圖**（`figures/hunting_rifles_type_A_B_compare.png`）。

## 資料夾

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 網頁本體 |
| `css/style.css` | 版面樣式 |
| `js/title.js` | p5.js 標題動畫，文字、顏色、動畫時間都在檔案開頭的 `CONFIG` |
| `js/compare.js` | 互動比較的程式，部位說明文字在 `INFO` |
| `js/lib/p5.min.js` | p5.js 1.11.3（LGPL-2.1，授權見 `p5-LICENSE.txt`） |
| `data/shapes.js` | 手繪線稿座標，依照片描繪，單位為原照片的像素 |
| `assets/` | 兩張實物影像（800 px 寬的截圖） |
| `figures/` | 靜態對照圖 |
| `notes/sources.md` | 來源與查核筆記 |

## 本機預覽

直接用瀏覽器打開 `index.html` 就能看。字型從 Google Fonts 載入，離線時會改用系統字型。

## 上線前

- `assets/` 裡的兩張照片分別屬於原住民族電視台，以及花蓮縣警察局／中央社。**取得刊登授權前，不要推到公開的 GitHub Pages。**
- 線稿是「手繪示意」，只畫照片看得到的外觀；分離動畫不代表實際拆解方式。
